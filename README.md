# IEEE Conference IIPS-CoMET 2026

Professional conference website for the International Conference on < To be Decided> (IIPS-CoMET 2026), hosted by the International Institute of Professional Studies (IIPS), Devi Ahilya Vishwavidyalaya (DAVV), Indore, India.

## Features

- **IEEE-Compliant Design**: Professional, academic layout with blue, gold, and white color scheme.
- **Dual Sticky Navigation**:
  - **Top Bar**: Static institution branding (IIPS, DAVV).
  - **Main Nav**: Primary conference navigation with hover effects and active state highlighting.
- **Announcements Ticker**: Scrollable announcements bar for latest updates.
- **Responsive Design**: Mobile-first approach with a slide-out mobile menu.
- **Key Features**:
  - Countdown timer to paper submission deadline.
  - Highlight cards for conference features.
  - Detailed speaker and committee sections.
  - Standard conference pages (Home, CFP, Committees, Keynotes, Venue, Registration, Contact).

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Heroicons](https://heroicons.com/)

## Installation & Development

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd ieee-comet
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```
    The site will be available at `http://localhost:3000`.

4.  **Build for production**:
    ```bash
    npm run build
    ```
    The static site will be generated in the `dist/` folder.
